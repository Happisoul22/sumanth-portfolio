# 🎨 Sathala Sumanth - Portfolio

A modern, responsive portfolio website showcasing my skills, services, and professional work as a full-stack developer.

## 📋 Overview

Welcome to my digital portfolio! This website presents my expertise in frontend development, backend engineering, and database design. Built with clean HTML, CSS, and modern web practices, it demonstrates my ability to create elegant, user-focused digital experiences.

## ✨ Features

- **Modern Dark Theme**: Eye-catching dark UI with blue accent colors and smooth animations
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Navigation**: Sticky navbar with smooth scrolling to different sections
- **Interactive Elements**: Hover effects, skill bars, and smooth transitions
- **Service Showcase**: Display of my core competencies and services
- **Contact Form**: Easy way for potential clients to reach out
- **Social Media Links**: Quick access to my social profiles

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and proper structure
- **CSS3**: Advanced styling with CSS variables, flexbox, and animations
- **Font Awesome**: Beautiful icon library for visual enhancements
- **Google Fonts**: Poppins font family for modern typography
